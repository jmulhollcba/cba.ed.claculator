# cba.ed.claculator
This code contains both UI and server code separately and combined. 
It is an RShiny app that dsplays a calculator. 
The calculator pulls from College Scorecard data to input projected earnings and cost of attendance figures for a user's selected college and program.
Monthly budget outlay data is pulled using user's selected post-college county
The calculator allows the user to input figures for loans and other budget variables.
The calculator outputs the monthly budget outlays including net savings based on these inputs including timeline to pay off any loans
